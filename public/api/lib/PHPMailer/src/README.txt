Drop official PHPMailer v6 sources here for Hostinger inbox delivery via the PHPMailer API:

  Exception.php
  PHPMailer.php
  SMTP.php

Download from:
https://github.com/PHPMailer/PHPMailer/tree/v6.9.3/src

If these files are absent, contact.php uses the bundled SmtpMailer.php (authenticated SMTP)
and falls back to PHP mail() only if SMTP fails.
